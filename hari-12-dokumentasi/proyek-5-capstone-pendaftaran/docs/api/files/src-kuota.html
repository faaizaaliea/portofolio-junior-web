    kuota.php

    Modul kuota pendaftaran dan pemindahan kelas yang aman dari balapan (race condition): transaksi + SELECT ... FOR UPDATE mengunci baris kelas sehingga dua pendaftar bersamaan tidak bisa sama-sama merebut kursi terakhir.

    ID Modul : MOD-KUO-001 Dependensi : src/pendaftar.php, src/log.php

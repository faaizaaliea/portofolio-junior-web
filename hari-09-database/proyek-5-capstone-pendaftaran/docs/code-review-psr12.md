# Code Review PSR-12 dan Commit

| Butir                                                   | Ya/Tidak | Catatan                                                                                                                                                                                                               |
| ------------------------------------------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `declare(strict_types=1)` dan tipe pada semua fungsi    | Ya       | Semua berkas logika di `src/`, `public/`, `config/database.php` memakainya; fungsi bertipe parameter dan return. Berkas tampilan (`_form.php`, `templates/*`) dan `config*.php` (hanya `return` array) sengaja tidak. |
| Tidak ada query yang menyambung input pengguna          | Ya       | Seluruh query di `src/pendaftar.php` berparameter. Satu-satunya pengecualian adalah `public/injeksi.php`, demo sengaja rentan, dikunci ke localhost + debug.                                                          |
| Hapus/ubah memakai POST dan token CSRF                  | Ya       | `hapus.php` menolak non-POST (405) dan memanggil `cekCsrf()`; form ubah memuat token. `ubah.php?id=` hanya menampilkan form (GET), penyimpanan lewat POST + CSRF.                                                     |
| Kredensial di luar repositori (`.gitignore`)            | Ya       | `config/config.php` di-ignore; hanya `config.contoh.php` yang di-commit.                                                                                                                                              |
| Error tidak tampil mentah ke pengguna                   | Ya       | `set_exception_handler` di `bootstrap.php` menampilkan pesan umum dan mencatat detail ke `error_log`. Atur `'debug' => false` di server nyata.                                                                        |
| Logika terpisah dari tampilan (`src/` vs `templates/`)  | Ya       | Akses data/validasi di `src/pendaftar.php`; HTML di `templates/` dan `public/_form.php`.                                                                                                                              |
| Penamaan konsisten (camelCase fungsi, snake_case kolom) | Ya       | `ambilPendaftar`, `emailSudahAda`, ...; kolom `nama_kelas`, `kelas_id`, `tgl_daftar`.                                                                                                                                 |

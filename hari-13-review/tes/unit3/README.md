# Hello World - Node.js

## Deskripsi

Proyek sederhana untuk mempelajari dasar penggunaan Node.js. Program ini menampilkan teks "Hello World" pada console.

## Teknologi

- Node.js
- JavaScript
- npm

## Struktur Proyek

```text
hari-09-nodejs/
├── src/
│   └── index.js
├── package.json
├── package-lock.json
└── README.md
```

## Cara Menjalankan

**Menggunakan Node.js:**

```bash
node src/index.js
```

**Menggunakan npm:**

```bash
npm start
```

## Output

```text
Hello World
```
